# RAG

![Python](https://img.shields.io/badge/Python-3.12+-blue?logo=python&logoColor=white)
![Ollama](https://img.shields.io/badge/Ollama-0.30+-orange?logo=ollama&logoColor=white)
![ruff](https://img.shields.io/badge/ruff-linter-green?logo=ruff&logoColor=white)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Данный проект я сделал, чтобы быстро искать необходимую информацию по документам 
на компьютере локально вместо постоянного закидывания их в Дипсик. Система на основе
Retrieval-Augmented Generation позволяет индексировать документы из разных 
источников и отвечать на вопросы пользователей, используя наиболее релевантные 
фрагменты из проиндексированных данных.

## Возможности

- **Индексация документов** - загрузка и обработка документов из URL‑адресов 
и локальных файлов.
- **Нарезка на чанки** - разбиение текста на смысловые фрагменты с настраиваемым 
размером и перекрытием.
- **Векторное хранилище** - индексация и поиск с использованием `Qdrant` (локально).
- **Генерация ответов** - использование LLM через `Ollama` для формирования ответов 
на основе найденных отрывков.
- **Гибкая настройка** - все параметры задаются через переменные окружения.

## Требования

- Python 3.12+
- [Ollama](https://ollama.com/) (любая модель, совместимая с API Ollama)
- Управление зависимостями: uv

По дефолту используются модели:
- Основная: [techwithsergiu/Qwen3.5-text-2B-GGUF:Q4_K_M](https://huggingface.co/techwithsergiu/Qwen3.5-text-2B-GGUF)
- Эмбеддинги: [embeddinggemma:300m](https://ollama.com/library/embeddinggemma:300m)

Они умещаются суммарно в 3 Гб VRAM. Модель для `embeddinggemma:300m` была выбрана 
из-за высокой позиции в рейтинге [MTEB для русского языка](https://huggingface.co/spaces/mteb/leaderboard)
при низком потреблении ресурсов (модель всего на 300 миллионов параметров). Вы можете
использовать свои модели. Свою модель можно установить в `.env` файле. В разделе 
`Установка` будет описано, как запустить с дефолтными для проекта моделями. 

## Установка

### 0. Установка и запуск Ollama

Установить Ollama можно с официального сайта проекта: 
https://ollama.com/

Установка моделей:

```bash
ollama pull ollama run hf.co/techwithsergiu/Qwen3.5-text-2B-GGUF:Q4_K_M
```

```bash
ollama pull embeddinggemma:300m
```

Запуск Ollama:

```bash
ollama serve
```

### 1. Клонирование репозитория

```bash
git clone https://github.com/bulatziyatdinov/rag.git
cd rag
```

### 2. Установка зависимостей

В проекте используется `uv` для управления зависимостями. Установите `uv`, 
если он ещё не установлен:

```bash
pip install uv
```

Затем установите зависимости проекта:

```bash
uv sync
```

### 3. Настройка окружения

Скопируйте пример конфигурационного файла `example.env` и отредактируйте его под себя, 
если необходимо:

```bash
cp example.env .env
```

## Использование

### 1. Индексация документов

Перед началом работы необходимо проиндексировать документы. Свои файлы необходимо 
поместить в папку `data`. Папку документов можно настроить через переменную окружения. 
Также можно указать ссылки на файлы, которые нужно скачать и проиндексировать,
в файле `urls.txt` (по одному на строку) и выполните:

```bash
uv run index.py
```

### 2. Запросы к системе

После индексации запустите интерактивный режим вопросов‑ответов:

```bash
uv run main.py
```

В интерактивном режиме доступны команды:
- `info` или `i` - показать текущую конфигурацию
- `exit`, `e`, `quit` или `q` - выйти из программы

Просто введите свой вопрос - система вернёт ответ, сгенерированный на основе 
наиболее релевантных фрагментов из проиндексированных документов.

## Конфигурация

Все настройки задаются через переменные окружения в файле `.env`:

| Переменная                   | Описание                                | Значение по умолчанию                              |
|------------------------------|-----------------------------------------|----------------------------------------------------|
| `RAG_DATA_DIR`               | Директория для хранения документов      | `data`                                             |
| `RAG_URLS_FILE`              | Файл со списком URL для индексации      | `urls.txt`                                         |
| `RAG_QDRANT_PATH`            | Путь для локального хранилища Qdrant    | `.store`                                           |
| `RAG_QDRANT_COLLECTION_NAME` | Имя коллекции в Qdrant                  | `rag`                                              |
| `RAG_OLLAMA_BASE_URL`        | URL сервера Ollama                      | `http://localhost:11434`                           |
| `RAG_LLM_MODEL`              | Модель LLM для генерации ответов        | `hf.co/techwithsergiu/Qwen3.5-text-2B-GGUF:Q4_K_M` |
| `RAG_EMBEDDING_MODEL`        | Модель для генерации эмбеддингов        | `embeddinggemma:300m`                              |
| `RAG_TEMPERATURE`            | Температура генерации                   | `0.25`                                             |
| `RAG_NUM_CTX`                | Размер контекстного окна                | `8192`                                             |
| `RAG_NUM_PREDICT`            | Максимальное число генерируемых токенов | `512`                                              |
| `RAG_REASONING`              | Включение режима рассуждений            | `false`                                            |
| `RAG_SEED`                   | Seed для воспроизводимости              | `42`                                               |
| `RAG_CHUNK_SIZE`             | Размер чанка при нарезке текста         | `500`                                              |
| `RAG_CHUNK_OVERLAP`          | Перекрытие между чанками                | `100`                                              |
| `RAG_SAVE_CHUNKS`            | Сохранять ли чанки на диск              | `true`                                             |
